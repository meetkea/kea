# Security policy

## Reporting a vulnerability

Please report suspected Kea security or privacy vulnerabilities privately to [hi@usekea.com](mailto:hi@usekea.com).

Include a concise description, affected version or commit, reproduction steps, and potential impact when available. Do not include real X passwords, cookies, tokens, or other sensitive account data.

Please avoid opening a public issue for an unpatched vulnerability. Kea does not currently offer a bug bounty or guarantee a specific response timeline.

# Code of conduct

Kea is committed to a welcoming, respectful, and harassment-free community.

## Expected behavior

- Be considerate and constructive.
- Discuss ideas and code without personal attacks.
- Respect different backgrounds, identities, experiences, and levels of expertise.
- Accept feedback gracefully and focus on what is best for the project and its users.

Harassment, discrimination, threats, unwanted sexual attention, publishing private information, and sustained disruptive behavior are not acceptable.

Project maintainers may edit or remove contributions and restrict participation when behavior conflicts with these expectations. Report conduct concerns privately to [hi@usekea.com](mailto:hi@usekea.com). Do not include sensitive personal information beyond what is necessary to understand the report.
